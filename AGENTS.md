# Consignes du projet

## Dépôt GitHub

Ce projet est publié sur `https://github.com/tbirostweb/dashboard`. Pour les commits et les push, utilise le dépôt `tbirostweb/dashboard` et sa branche courante. N'utilise pas le compte personnel `theobirost` comme destination. L'identité Git locale du projet est BirostWeb. Ne publie jamais les fichiers `.env`, les clés, les bases de données locales, les données privées ou les sorties générées.
